# ServiceFlow

**ServiceFlow** — Cпециализированная SaaS-платформа для онлайн-бронирования и финансового учета услуг малого бизнеса и самозанятых специалистов.

## О проекте

Платформа решает две ключевые задачи:
- **Для специалистов** — управление расписанием, клиентской базой и финансами
- **Для клиентов** — удобный поиск и онлайн-запись к специалистам

## Функциональные возможности

### Для специалистов
- 📅 Онлайн-бронирование с автоматическим календарем
- 💰 Финансовый учет доходов и расходов
- 👥 CRM для управления клиентами
- 📊 Аналитика и отчеты
- 🔔 Автоматические напоминания клиентам
- ⚙️ Настройка каталога услуг и рабочего расписания

### Для клиентов
- 🔍 Поиск специалистов по категориям
- 📱 Просмотр свободных слотов в реальном времени
- ✍️ Онлайн-запись в несколько кликов
- ✅ Подтверждение и напоминания о записи
